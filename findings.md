Findings

Top Stories

Retrieved the five highest-scoring stories from the Hacker News dataset.

User Score Analysis

Calculated the total score across all stories and identified users whose combined scores exceeded 200 points.

Percentage Contribution

Calculated the percentage contribution of selected high-scoring users relative to the total score.

Rickroll URL Analysis

Identified users who posted the Rickroll YouTube link and counted the number of times it was posted by each user.

Source Categorization

Grouped stories into the following categories based on their URLs:

* GitHub
* Medium
* New York Times
* Other

Counted the number of stories in each category.

Time-Based Analysis

Examined story activity by extracting the hour from each timestamp using the STRFTIME() function.

Calculated:

* Average score by hour
* Number of stories by hour
